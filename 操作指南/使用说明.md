# 个人网站 · 操作指南

## 一、怎么打开网页（在自己电脑上预览）

> ⚠️ 不要直接双击 `index.html`。那样打开会缺样式、缺内容，因为网页需要通过一个"本地服务器"来加载。

**方法 1（最简单）**
双击本文件夹里的 **`双击打开本地预览.bat`**
→ 会弹出一个黑色窗口，浏览器自动打开 **http://localhost:8000**
→ 修改文件后，在浏览器里按 `F5` 刷新即可看到变化
→ 看完后关闭黑色窗口即停止

**方法 2（命令行）**
在网站文件夹（`个人网页和cv`）里打开终端，运行：

```
python 操作指南/serve.py
```

> `localhost:8000` 只是**你自己电脑上的临时地址**，别人打不开。要让所有人都能访问，需要按第二部分发布到 GitHub。

3. GitHub 仓库 → **Settings → Pages → Custom domain** 填入域名，保存，勾选 **Enforce HTTPS**
4. 等几分钟到几小时生效。原来的 `用户名.github.io` 会自动跳转到新域名

## 三、发布到 GitHub（第一次，已完成 ✅，仅供参考）

1. 登录 GitHub，点右上角 **+ → New repository**
   - Repository name 必须填：**`你的用户名.github.io`**
   - 选 **Public**，其他都不勾，点 Create
2. 在网站文件夹打开终端，依次运行（把 `USERNAME` 换成你的用户名）：

   ```
   git init
   git add .
   git commit -m "Initial website"
   git branch -M main
   git remote add origin https://github.com/USERNAME/USERNAME.github.io.git
   git push -u origin main
   ```

   第一次 push 会弹窗让你登录 GitHub，按提示登录即可。
3. 仓库页面 → **Settings → Pages** → Source 选 **Deploy from a branch**，Branch 选 **main** 和 **/ (root)** → Save
4. 等 1–2 分钟，打开 `https://USERNAME.github.io` 就能看到网站了

## 四、以后更新网站

> 本地文件改了 ≠ 线上网站变了。必须"推送"（push）到 GitHub，线上网站才会更新。

**方法 1：让 Claude 帮你**
直接说"推送更新"即可。

**方法 2：自己操作**
在网站文件夹（`个人网页和cv`）里打开终端，依次运行：

```
git add .
git commit -m "Update content"
git push
```

- 1–2 分钟后线上网站自动更新
- 如果浏览器还显示旧版，按 `Ctrl + F5` 强制刷新
- 想先在本地看效果再上线：先双击 `双击打开本地预览.bat` 检查，没问题再推送

**注意**
- `照片/` 文件夹不会被上传（已在 `.gitignore` 中排除），原图不会公开
- 网站用的头像是裁剪后的 `assets/img/photo.jpg`，换头像就替换这个文件

## 五、改内容去哪里

| 想改的内容 | 文件 |
|---|---|
| 姓名、简介、News、论文、项目、奖项、Talks、博客列表、相册、技能、经历 | `assets/js/data.js`（几乎所有内容都在这里） |
| 头像 | 存为 `assets/img/photo.jpg` |
| CV PDF | 存为 `assets/cv.pdf` |
| 写一篇博客 | 复制 `blog/2019-guizhou-volunteer-teaching.html` 改名改内容（中英双语写在 `data-lang="en"` / `data-lang="zh"` 两段里），再在 `data.js` 的 `posts` 加一条 |
| 配色 | `assets/css/style.css` 开头的 `:root` |

任何列表（如 `news`、`talks`、`publications`）留空 `[]`，对应板块会自动隐藏。

**中英文切换**：网页右上角的「中文 / EN」按钮会切换整个网站的语言，并记住访客的选择。
- 导航、标题、按钮等界面文字：已内置中英文，不用管
- 你的内容：在 `data.js` 里写成 `{ en: "English", zh: "中文" }` 即可；只写一个字符串则中英文显示相同（论文标题、人名一般这样）
- 日期写英文即可（如 `"Sep 2022 – Present"`），中文模式会自动显示为 `2022.09 – 至今`
- 想直接分享中文版链接：在网址后加 `?lang=zh`，如 `https://anqitan.github.io/?lang=zh`
在 `data.js` 里搜索 `TODO` 可以找到所有还需要确认或补充的地方。

## 六、更新 CV（自动生成）

CV 是根据 `assets/js/data.js` 自动生成的，所以**网站内容改了，CV 重新生成一次就同步了**。

1. 在 `操作指南/生成CV` 文件夹打开终端
2. 第一次使用先运行：`npm install`
3. 之后每次运行：`node make_cv.js`

会生成三个文件：
- `assets/cv.pdf`：网站上 CV 按钮链接的文件（用本机 Edge 打印生成）
- `操作指南/生成CV/output/CV_Anqi_Tan.docx`：Word 版，可以手动微调后用于投递
- `操作指南/生成CV/output/CV_Anqi_Tan.html`：排版源文件

然后照常 `git add . / git commit / git push` 上线。

注意：
- 想调整 CV 的版块或措辞（比如毕设、DoD 项目那几句），改 `make_cv.js` 里对应段落即可

### 按岗位的一页版 resume

在 `操作指南/生成CV` 文件夹运行：`node make_resume.js`

会生成 3 份一页英文 resume，放在 `assets/resumes/`，网站 CV 页顶部“下载简历”卡片可以直接下载：

| 版本 | 侧重点 |
|---|---|
| Medical Devices & Instrumentation | 便携读取仪、光学、机械设计 |
| Diagnostics & Assay Development | 侧向流检测开发、人体样本验证、临床合作 |
| AI & Data for Health | 图像分析、大语言模型工具、黑客松获奖 |

- 措辞都在 `make_resume.js`：上面是“素材库”（每条经历的写法），下面 `VARIANTS` 决定每个版本用哪几条、按什么顺序、技能怎么排
- 想加新版本（比如“咨询/产品经理”）：在 `VARIANTS` 里复制一项改 id 和内容，再在 `data.js` 的 `resumes` 里加一张卡片
- 改完运行脚本，打开 PDF 确认还是一页，然后照常推送
