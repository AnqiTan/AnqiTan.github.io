# 个人网站 · 操作指南

## 一、怎么打开网页（在自己电脑上预览）

> ⚠️ 不要直接双击 `index.html`。那样打开会缺样式、缺内容，因为网页需要通过一个"本地服务器"来加载。

**方法 1（最简单）**
双击本文件夹里的 **`双击打开本地预览.bat`**
→ 会弹出一个黑色窗口，浏览器自动打开 **http://localhost:8000**
→ 修改文件后，在浏览器里按 `F5` 刷新即可看到变化
→ 看完后关闭黑色窗口即停止

**方法 2（命令行）**
在网站文件夹（`个人网页和cv`）里打开终端，运行：

```
python 操作指南/serve.py
```

> `localhost:8000` 只是**你自己电脑上的临时地址**，别人打不开。要让所有人都能访问，需要按第二部分发布到 GitHub。

### 自定义域名（可选，约 $10–15/年）

如果想要像 `xinyulian.tech`、`boerchen.com` 那样的独立域名：

1. 在 Namecheap / Cloudflare / GoDaddy 等网站购买域名（如 `yourname.com`）
2. 在域名商的 DNS 设置里添加：
   - 4 条 **A 记录**，主机 `@`，指向：
     `185.199.108.153`、`185.199.109.153`、`185.199.110.153`、`185.199.111.153`

3. GitHub 仓库 → **Settings → Pages → Custom domain** 填入域名，保存，勾选 **Enforce HTTPS**
4. 等几分钟到几小时生效。原来的 `用户名.github.io` 会自动跳转到新域名

## 三、发布到 GitHub（第一次，已完成 ✅，仅供参考）

1. 登录 GitHub，点右上角 **+ → New repository**
   - Repository name 必须填：**`你的用户名.github.io`**
   - 选 **Public**，其他都不勾，点 Create
2. 在网站文件夹打开终端，依次运行（把 `USERNAME` 换成你的用户名）：

   ```
   git init
   git add .
   git commit -m "Initial website"
   git branch -M main
   git remote add origin https://github.com/USERNAME/USERNAME.github.io.git
   git push -u origin main
   ```

   第一次 push 会弹窗让你登录 GitHub，按提示登录即可。
3. 仓库页面 → **Settings → Pages** → Source 选 **Deploy from a branch**，Branch 选 **main** 和 **/ (root)** → Save
4. 等 1–2 分钟，打开 `https://USERNAME.github.io` 就能看到网站了

## 四、以后更新网站

改完内容后，在网站文件夹的终端运行：

```
git add .
git commit -m "Update content"
git push
```

1–2 分钟后线上网站自动更新（如果没变，浏览器按 `Ctrl + F5` 强制刷新）。

## 五、改内容去哪里

| 想改的内容 | 文件 |
|---|---|
| 姓名、简介、News、论文、项目、奖项、Talks、博客列表、相册、技能、经历 | `assets/js/data.js`（几乎所有内容都在这里） |
| 头像 | 存为 `assets/img/photo.jpg` |
| CV PDF | 存为 `assets/cv.pdf` |
| 写一篇博客 | 复制 `blog/hello-world.html` 改名改内容，再在 `data.js` 的 `posts` 加一条 |
| 配色 | `assets/css/style.css` 开头的 `:root` |

任何列表（如 `news`、`talks`、`publications`）留空 `[]`，对应板块会自动隐藏。
